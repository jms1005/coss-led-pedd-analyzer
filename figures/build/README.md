# 제작 도면 사용법

차광 챔버를 만들 때 보면서 작업하는 A4 6장입니다.
치수의 출처는 `docs/차광챔버_제작.md` 4절이고, 도면은 그것을 그림으로
옮긴 것입니다. **치수를 바꾸려면 문서를 먼저 고치고 도면을 다시 만드세요.**

| 장 | 내용 | 실척 |
|---|---|---|
| 1 | 무엇을 만드는가 — 조립 그림 + 부품 10개 목록 | — |
| 2 | 재단 템플릿 ① 바닥·뚜껑·마개 | **1:1** |
| 3 | 재단 템플릿 ② 벽 4장 (LED 구멍 위치) | **1:1** |
| 4 | 재단 템플릿 ③ 지그·슬릿 | **1:1** |
| 5 | 조립 순서 8단계 | — |
| 6 | 단면도 · 누광 검사 · 완성 체크리스트 | — |

## 만들기

```
sh tools/make_build_pdf.sh          # SVG 6장 + docs/제작도면.pdf 까지
python tools/make_build_drawings.py # SVG 만 다시
```

## 인쇄 — 배율이 전부입니다

2·3·4장은 **오려서 우드락에 대고 그대로 자르는 템플릿**입니다.
1mm라도 축소되면 조각이 안 맞습니다.

1. `docs/제작도면.pdf` 를 열고 `Ctrl+P`
2. 용지 **A4**, 여백 **없음**, 배율 **기본(100%)**
3. **"페이지에 맞춤"이 켜져 있으면 끕니다** — 이게 가장 흔한 실수입니다
4. 인쇄한 뒤 2·3·4장 위쪽의 **100mm 눈금자를 자로 재봅니다.**
   정확히 100mm가 아니면 배율을 고쳐 다시 뽑습니다

`figures/build/print.html` 을 브라우저로 열어 바로 인쇄해도 됩니다.
화면에 뜨는 빨간 안내는 인쇄물에 나오지 않습니다.

## 큐벳을 잰 뒤에 3장만 다시 뽑기

LED 구멍 높이(광축)는 큐벳의 맑은 구간을 재봐야 정해집니다.
그전까지 3장의 구멍은 **빨간 점선**으로, 잠정값 20mm 자리에 그려져 있습니다.

실측이 끝나면 그 값으로 다시 만들고 3장만 인쇄하세요.

```
python tools/make_build_drawings.py --axis 17
```

`--axis` 는 **챔버 바닥에서 광축까지의 높이(mm)** 입니다.
지그 두께 5mm + 큐벳 바닥에서 광축까지의 높이로 계산합니다.

## 구성

| 파일 | 역할 |
|---|---|
| `tools/build_drawings_lib.py` | 도형·치수선·아이소메트릭 그리기 도구 |
| `tools/make_build_drawings.py` | 시트 6장의 내용 |
| `figures/build/sheet1~6.svg` | 생성물. **직접 고치지 마세요** — 다시 만들면 덮어씁니다 |
| `figures/build/print.html` | A4 인쇄 래퍼 (여백 0, mm 고정) |
| `tools/make_build_pdf.sh` | 위를 묶어 `docs/제작도면.pdf` 생성 |

SVG는 1 단위 = 1mm로 그려져 있고, 생성할 때마다 용지 크기와 viewBox가
A4인지 자체 점검합니다. 어긋나면 오류를 내고 멈춥니다.
