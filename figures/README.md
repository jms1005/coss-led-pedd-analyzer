# 그림 파일 사용법

계획서에 "삽입 예정"으로 비어 있던 두 자리를 채우는 그림입니다.

| 파일 | 용도 | 내용 |
|---|---|---|
| `fig1_block_diagram.svg` | 계획서 3.1절 `[그림 1]` | 시스템 블록도 (6블록 구성) |
| `fig2_program_flow.svg`  | 계획서 6.8절 `[그림 2]` | 프로그램 흐름도 |
| `fig3_schematic.svg`     | **제출물 「나. 회로도」** | 전체 시스템 회로도 |
| `fig3_schematic_print.html` | 위 회로도의 PDF 변환용 | 인쇄 래퍼 |

회로도는 `tools/make_schematic.py`가 생성합니다. 부품 값이나 핀 배정이
바뀌면 스크립트를 고치고 다시 실행하세요.

```
python tools/make_schematic.py
```

## Word / PowerPoint에 넣는 방법

Office 2016 이상은 SVG를 그대로 지원합니다.

`삽입 > 그림 > 이 디바이스` 에서 SVG 파일을 선택하면 됩니다.
SVG는 벡터라서 크기를 키워도 글자가 흐려지지 않으므로, 발표 슬라이드에
꽉 채워 넣어도 깨끗하게 보입니다.

> Office 버전이 낮아 SVG가 안 들어가면, 브라우저에서 SVG 파일을 열고
> 화면을 캡처해 PNG로 넣어도 됩니다. 다만 인쇄 품질은 떨어집니다.

## 그림 1이 담고 있는 내용

계획서 3.1절이 규정한 6블록을 그대로 반영했습니다.

- ① MCU 코어 — 보정·정규화·분류, 발광 채널 순차 제어
- ② RGB 발광부 — PB0/PB1/PB2, 한 번에 하나만 점등
- ③ 광학 경로 — 차광 챔버 + 큐벳, 투과 배치
- ④ 검출부 — 역방향 바이어스된 검출 LED, PD7(AIN1)
- ⑤ 신호 처리부 — Analog Comparator + Timer1 Input Capture
- ⑥ 출력부 — UART / I²C OLED

점선 사각형은 ATmega328P 칩 경계입니다. **⑤ 신호 처리부가 칩 내부에
있다는 점이 이 그림의 핵심 메시지**입니다. 전통적 방식이라면 이 자리에
TIA(트랜스임피던스 증폭기)와 ADC가 외부 부품으로 들어가야 하는데,
본 설계는 그것을 MCU 내장 하드웨어로 대체했습니다.
경제성·난이도 평가 항목을 설명할 때 이 그림을 근거로 쓰면 됩니다.

## 그림 2가 담고 있는 내용

계획서 6.8절의 11단계를 그대로 따랐습니다. 파장 루프(R→G→B)를 점선
박스로 묶어 반복 구간을 시각적으로 분리했고, Timeout 예외 경로를 빨간색으로
따로 표시했습니다. 예외 처리는 요강 3-마 "예외적 경우에 대한 대비"에
해당하는 평가 항목이므로, 흐름도에 드러나 있는 편이 유리합니다.

## 회로도 (그림 3) — 제출용 PDF 만들기

요강 「4. 예선 제출물 - 나」가 회로도를 **PDF 파일**로 요구합니다.

1. `fig3_schematic_print.html`을 브라우저로 엽니다 (더블클릭)
2. `Ctrl+P`
3. 대상 → **PDF로 저장**
4. 용지 **A3**, 방향 **가로**
5. 더보기 설정 → **배경 그래픽** 체크 (이걸 빼면 색이 사라집니다)
6. 저장

화면의 안내 문구는 인쇄물에 나오지 않도록 처리해 두었습니다.

### 회로도의 설계 의도

심사에서 설명할 때 짚어야 할 지점들입니다.

**D4의 극성이 나머지와 반대입니다.** 도면에서 D1~D3은 삼각형이 오른쪽을,
D4는 왼쪽을 향합니다. 화살표 방향도 발광은 바깥, 검출은 안쪽입니다.
이 한 가지가 본 설계의 핵심이므로 기호 수준에서 구분해 그렸습니다.

**아날로그 프론트엔드가 없습니다.** 기존 방식이라면 검출 소자와 MCU 사이에
TIA용 OP-AMP와 피드백 저항·커패시터가 들어가야 하지만, 이 도면에는 D4에서
PD7로 바로 연결됩니다. 경제성(요강 3-라)을 설명할 때 이 빈 자리를 근거로
쓰면 됩니다.

**AREF가 미접속(N.C.)입니다.** ADC를 쓰지 않는다는 설계 판단을 도면에
드러낸 것입니다. Analog Comparator와 Timer1 Input Capture로 대체했다는
서술(요강 3-다 하드웨어·소프트웨어 배분)과 연결됩니다.
