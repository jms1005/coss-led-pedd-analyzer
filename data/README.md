# 측정 데이터 폴더

시리얼 터미널 로그를 시료별로 나눠 이곳에 저장합니다.
**파일 이름(확장자 제외)이 분석 결과의 시료 이름으로 사용됩니다.**

권장 이름:

```
data/dark.csv        빈 챔버 (암전류 기준)
data/distilled.csv   증류수
data/dye.csv         착색수
data/milk.csv        희석 우유 (탁도)
```

분석 실행:

```
python tools/analyze.py data/distilled.csv data/dye.csv data/milk.csv
```

## 기록 규칙 (계획서 6.6절)

- **보정 후 값이 아닌 원시 값을 저장합니다.** 보정식이 나중에 바뀌어도
  원시 데이터가 있으면 재계산할 수 있습니다.
- 로그 파일과 함께 아래 항목을 메모로 남깁니다:
  시료 ID, 측정 순번, 타임스탬프, 주변 조명 조건, 큐벳 방향/주입량
- 세션 시작과 종료 시 증류수를 각각 측정해 드리프트를 확인합니다.
- 시료 측정 순서는 세션마다 무작위화합니다. 항상 같은 순서로 측정하면
  온도 변화나 LED 발열에 따른 드리프트가 시료 간 차이로 위장됩니다.
