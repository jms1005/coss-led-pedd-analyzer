# 실수 방지 체크리스트

2026-09-05 Phase 1 브링업에서 **실제로 겪은 실수**를 정리한 문서입니다.
가정이 아니라 그날 하드웨어에서 나온 값을 근거로 씁니다.

Phase 2에서는 LED를 3개 더 꽂고, Phase 4에서는 버튼과 OLED가 붙습니다.
같은 실수가 반복될 자리가 정확히 그곳입니다.

---

## 1. 증상 → 원인 대조표 (실측 기준)

측정값만 보고 원인을 가릅니다. **1 tick = 500ns.**

| 증상 | 원인 | 조치 |
|---|---|---|
| 값이 **0~1 tick 고정** | 검출 LED 극성 반대 | 그대로 180° 돌려 꽂기 |
| **전 채널 TIMEOUT** (ovf 61, 약 2초) | 검출 LED 미접속·단선 | 다리와 D7 점퍼를 다시 꽂기 |
| 값이 충전 시간에 계속 끌려다님 | 충전 경로 직렬 저항 (접촉 불량) | 다리·점퍼 재삽입 |
| 노출 6µs / 차광 시 45µs | 정상. 환경광이 압도 | 차광 챔버 필요 |
| 빛을 막았는데 값이 그대로 | **차광이 실제로 안 됐을 가능성부터** | 아래 3절 참조 |

`0~1 tick`과 `TIMEOUT`은 **정반대 원인**입니다. 헷갈리면 진단이 반대로 갑니다.

> 배선도 초판에는 "거꾸로 꽂으면 전부 TIMEOUT"이라고 적혀 있었는데
> **틀린 서술이었습니다.** 실측 결과 0~1 tick 이 나왔고, 도면을 수정했습니다.

## 2. LED 극성 — 눈이 아니라 값으로 판정합니다

브링업에서 검출 LED를 **두 번 반대로** 꽂았습니다. 두 번 다 "짧은 다리를
D7에 꽂았다"고 확신한 상태였습니다. 다리 길이로 판별하는 방식이
이 프로젝트에서는 신뢰할 수 없다는 뜻입니다.

**판별 순서**

1. **렌즈 안을 봅니다.** 투명 렌즈 안쪽에 **큰 컵(반사컵)** 이 보이는 쪽이
   캐소드(−)입니다. 다리를 잘라도 이 단서는 남습니다.
2. 꽂고 나서 **값으로 확인합니다.** `0~1 tick` 이면 뒤집힌 것입니다.
   그대로 180° 돌려 꽂으면 됩니다.

**지시는 다리 이름이 아니라 물리적 동작으로 주고받습니다.**
"짧은 다리를 D7에" 대신 **"지금 그대로 180° 돌려 꽂으세요"** 가 안전합니다.
어느 쪽이 짧은 다리인지에 대한 합의가 필요 없기 때문입니다.

### 발광 LED와 검출 LED는 위험도가 다릅니다

| | 극성 틀렸을 때 |
|---|---|
| 발광 LED (PB0/PB1/PB2) | 220Ω 저항이 있어 **그냥 안 켜집니다.** 안전 |
| **검출 LED (PD7)** | 저항이 없어 **순방향으로 과전류가 흐릅니다** |

검출 LED만 전류 제한 저항 없이 핀에 직결됩니다. 거꾸로 꽂으면 충전 펄스마다
정격을 넘는 전류가 흐릅니다. 100µs 펄스라 괜찮을 거라고 넘겨짚지 마세요.
소자가 상했는지는 이번에 확정하지 못했지만, 위험 자체는 실재합니다.

### 처음 꽂을 때 — 임시 저항으로 안전하게 확인하기

> ⚠️ **아래 절차는 아직 하드웨어에서 검증하지 않았습니다.**
> 이 문서의 나머지는 2026-09-05 브링업 실측이 근거이지만, 이 절만은
> 회로 이론으로 도출한 제안입니다. 실제로 해 본 뒤 결과를 여기에 덧붙이세요.

극성은 값으로만 확정할 수 있는데, **값을 보려면 일단 꽂아야 합니다.**
그런데 잘못 꽂은 상태로 꽂는 순간이 바로 과전류가 흐르는 순간입니다.
이 앞뒤가 막힌 상황을 임시 저항으로 풉니다.

**절차**

1. D7 과 검출 LED 사이에 **220Ω 을 임시로** 끼웁니다 (발광용과 같은 값)
2. 업로드하고 로그를 봅니다
   - `0~1 tick` 고정 → **뒤집힘.** 저항이 막아 줘서 안 상합니다. 180° 돌려 꽂기
   - 정상 범위 값 → 극성 맞음
3. 저항을 빼고 **직결로 되돌린 뒤** 본 측정을 합니다

**왜 본 측정에서는 빼는가**

| | 저항을 끼웠을 때 |
|---|---|
| 측정 원리 | **지장 없음.** 방전 중 핀은 하이 임피던스라 저항 양단 전압차가 거의 0 |
| 뒤집혔을 때 전류 | (5V−2V)÷220Ω ≈ **14mA** — 정격 안쪽 |
| 대가 | 브레드보드 접점 2개 증가, 고임피던스 노드가 길어져 노이즈에 더 취약 |
| 문서 | 배선도·제작도면·계획서 6.1절이 모두 **직결** 기준 |

측정 자체는 저항이 있어도 성립합니다. 다만 **접촉 불량 지점이 늘고**
방전 노드가 길어지는 것이 이 프로젝트에서 실제로 겪은 실패 유형과 겹칩니다.
그래서 **가장 위험한 순간(처음 꽂아보는 때)에만** 쓰고 빼는 것입니다.

**확인해야 할 것**

임시 저항을 낀 상태에서도 뒤집힘 증상이 `0~1 tick` 그대로인지는
**실측으로 확인해야 합니다.** 저항이 붙으면 비교기가 보는 노드의 정전용량이
달라져 파형이 바뀝니다. 정상 극성일 때의 값도 저항 유무로 조금 달라질 수
있습니다(노드 부유 용량이 몇 pF 늘어남).

**영구적으로 넣으려면** — Phase 1 에서 직결과 저항 삽입을 각각 10회 이상
측정해 **변동계수가 나빠지지 않는지** 확인한 뒤, 배선도·제작도면·
`firmware/README.md`·계획서 6.1절·`구매목록.md` 를 함께 갱신해야 합니다.
값은 100~220Ω 이면 충분하고, 1k 이상으로 키우면 노드 임피던스가 올라가
오히려 노이즈에 취약해집니다.

## 3. 차광은 "했다"가 아니라 "됐다"를 확인합니다

브링업에서 가장 큰 오진이 여기서 나왔습니다.

> 손으로 검출 LED를 덮고 측정 → 값이 안 변함 → "LED가 열화됐다"고 결론

**틀렸습니다.** 손이 제대로 덮이지 않았을 뿐이었습니다. 차광이 안 된 상태를
"차광했다"고 전제하는 바람에, 멀쩡할 수도 있는 소자를 불량으로 판정했습니다.

**차광이 됐는지 확인하는 기준값** — 손으로 덮었을 때 값이 노출 상태의
**최소 5배 이상** 늘어나야 합니다. 실측에서 6µs → 45µs(약 7배)였습니다.
거의 안 변하면 차광이 실패한 것이지 소자 문제가 아닙니다.

챔버가 완성되면 이 값은 훨씬 더 커져야 합니다. 챔버 안에서 DARK가
손으로 덮은 45µs 수준에 머문다면 **챔버에 빛이 새고 있습니다.**

## 4. 한 번에 한 가지만 바꿉니다

브링업에서 **LED 교체와 차광 품질이 동시에 바뀌어** 어느 쪽이 원인인지
분리할 수 없게 됐습니다. 그래서 "이전 LED가 죽었는가"라는 질문이
아직 미해결로 남아 있습니다.

**측정 조건을 바꿀 때 지킬 것**

- 한 번에 하나만 바꾸고, 바꾸기 전과 후를 각각 기록합니다.
- 바꾸기 전에 **예상 결과를 먼저 적습니다.** 예상이 빗나가면 조치가 아니라
  이해가 틀린 것이므로, 다음 조치로 넘어가지 말고 멈춰서 다시 봅니다.
- 되돌릴 수 있게 바꿉니다. 뽑은 부품은 버리지 말고 표시해서 보관합니다.

## 5. Phase 진입 전 체크리스트

### Phase 2 — 녹·청 채널 추가 (11~26 열)

- [ ] **한 채널씩** 추가합니다. 녹 꽂고 로그 → 청 꽂고 로그.
      3개를 한꺼번에 꽂으면 문제가 생겼을 때 범인을 못 찾습니다.
- [ ] 적색 채널(2~8 열)과 검출 LED(3·5 열)는 **건드리지 않습니다.**
      챔버 정렬과 측정 기준선이 이동합니다.
- [ ] 채널을 추가할 때마다 **증류수 기준값을 다시 잽니다.**
- [ ] 검출 LED는 적색 하나로 R·G·B를 모두 받습니다. 교체하지 않습니다.

### Phase 3 — 개체차 측정

- [ ] LED를 교체하면 **기준선이 이동합니다.** 교체 전후로 증류수를 각각 재서
      이동량을 기록한 뒤 비교합니다.
- [ ] 개체마다 표시(번호)를 붙이고 로그 파일명에 남깁니다.

### Phase 4 — 버튼·OLED 추가

- [ ] 버튼은 **대각선 두 다리**를 씁니다. 같은 변의 두 다리는 항상 붙어 있습니다.
- [ ] OLED는 브레드보드를 거치지 않고 우노에 직결합니다 (5V·GND·A4·A5).
- [ ] OLED를 붙인 뒤 **측정값이 변하지 않는지** 확인합니다. I²C 통신이
      측정 구간에 끼면 타이밍이 흔들립니다.

### 모든 측정 세션 공통 (계획서 6.6절)

- [ ] 세션 **시작과 종료에 증류수**를 각각 측정해 드리프트를 확인합니다.
- [ ] 시료 측정 순서를 세션마다 **무작위화**합니다. 같은 순서로만 재면
      온도 드리프트가 시료 간 차이로 위장됩니다.
- [ ] **원시 값**을 저장합니다. 보정식은 나중에 바뀔 수 있습니다.
- [ ] 로그와 함께 조명 조건·큐벳 방향·주입량을 메모로 남깁니다.

## 6. 배선 전 마지막 3가지

1. 검출 LED의 **캐소드(렌즈 안 큰 컵 쪽)** 가 D7인가
2. 5V와 GND가 어디에서도 직접 맞닿아 있지 않은가
3. 부품 다리끼리 서로 닿아 있지 않은가

**세 가지를 다 확인한 뒤에 USB를 꽂습니다.**

처음 꽂아보는 것이라면 2절의 **임시 저항 절차**를 먼저 보세요.
