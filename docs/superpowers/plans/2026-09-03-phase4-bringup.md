# Phase 4 하드웨어 브링업 순서

부품 도착 후 이 순서대로 진행한다. **한 번에 다 연결하면 어디가 문제인지 모른다.**

지금까지 검증된 것은 "컴파일이 되고 계산 로직이 맞다"까지다. 아래 항목은
실물이 있어야만 확인되는 것들이다.

> **배선은 `docs/배선도.pdf` (A4 4장) 를 보면서 하세요.** 어느 구멍에
> 무엇을 꽂는지 그림과 확인표로 나와 있습니다. 이 문서는 *언제 무엇을
> 연결하고 무엇을 확인하는지*의 순서를 잡고, 배선도는 *어떻게 꽂는지*를
> 담당합니다.
>
> 이 문서는 단계마다 부품을 하나씩 늘려 가며 확인하는 순서입니다.
> 배선도 3장의 6단계를 한 번에 다 하지 말고, 아래 순서를 따르세요.

---

## 0. 준비

- [ ] CH340 드라이버 설치 → 장치 관리자에서 COM 번호 확인
- [ ] 터미널 프로그램 준비 (PuTTY / Tera Term), **38400 bps 8N1**

> avrdude 는 이미 설치되어 있다 (winget `AVRDudes.AVRDUDE` 8.2).
> 업로드 명령의 `COM3` 부분만 실제 번호로 바꾼다.

## 1. 툴체인 검증 — 배선 없음

- [ ] `01_blink` 업로드
- [ ] 보드의 `L` LED 가 **1초 주기로 점멸**

여기서 막히면 COM 번호나 F_CPU 문제다. 다음으로 넘어가지 말 것.

## 2. 버튼 — 스위치만 연결

배선: **D2 ↔ 택트 스위치 ↔ GND** (외부 저항 없음. 내부 풀업 사용)

- [ ] `04_phase4` 업로드
- [ ] 전원이 들어가면 UART 로 **CSV 헤더 2줄**이 나온다
      (`# LED PEDD ANALYZER PHASE4` / `DARK,R,G,B,n0,n1,n2,cls,d2`).
      여기까지는 버튼과 무관하므로 **포트·보드레이트 확인용**으로 먼저 쓴다
- [ ] 짧게 누름 → **아무 일도 일어나지 않는 것이 정상.** 학습 전이라
      `g_trained == 0` 이고, `main.c` 는 학습된 상태에서만 짧게 누름을
      측정으로 받는다 (화면에도 `NOT TRAINED` 가 떠 있다)
- [ ] **2초 길게 누름 → 이어서 짧게 누름** → 그제서야 측정이 돌고
      UART 로 로그 1행이 나온다 (검출 LED 가 없어 `TIMEOUT` 이 정상)

> **길게 누름 자체는 UART 에 아무것도 남기지 않는다.** 학습 모드 진입은
> 화면만 바뀌므로, OLED 가 없는 이 단계에서는 "길게 → 짧게" 를 해봐야
> 버튼이 살아 있는지 확인된다.
>
> OLED 가 없어도 **UART 는 나와야 한다.** 헤더조차 안 나오면 업로드·포트
> 문제이고, 헤더는 나오는데 "길게 → 짧게" 에 반응이 없으면 스위치 배선이나
> 디바운스 문제다.

## 3. OLED — 화면만 연결

배선: **SDA→A4, SCL→A5, VCC→5V, GND→GND**

- [ ] 전원 인가 시 `LED PEDD ANALYZER` / `NOT TRAINED` 화면이 뜸

**안 나오면 I²C 주소 문제일 가능성이 가장 높다.**
`firmware/common/ssd1306.h` 의 `SSD1306_ADDR` 을 `0x3C` → `0x3D` 로 바꿔
재빌드한다. 그래도 안 나오면 배선(SDA/SCL 반대)을 의심한다.

- [ ] 글자가 깨지거나 상하가 뒤집혀 보이면 `INIT_SEQ` 의 `0xA1`(좌우 반전),
      `0xC8`(상하 반전)을 각각 `0xA0`, `0xC0` 으로 바꿔 시도

## 4. 광학계 — LED 4개 연결

배선은 `firmware/README.md` 3-1절 표를 따른다.
**D4(검출 LED)만 극성이 반대다** — 핀 7 → 캐소드(짧은 다리).

- [ ] `02_phase1` 로 측정값이 나오는지 먼저 확인
- [ ] 증류수와 우유의 방전 시간이 **눈에 띄게 다른지** 확인

여기서 차이가 없으면 Phase 4 를 해봐야 의미가 없다. 광량·거리·차광을
먼저 조정한다 (계획서 4.5절 실패 대응표).

## 5. 통합 — Phase 4 전체

- [ ] `04_phase4` 업로드
- [ ] 2초 길게 → `LEARN 1/3 DISTILLED WATER` → 증류수 넣고 짧게
- [ ] `LEARN 2/3 DYE WATER` → 착색수 넣고 짧게
- [ ] `LEARN 3/3 MILK` → 희석 우유 넣고 짧게
- [ ] `SAVED TO EEPROM` 표시
- [ ] **전원을 껐다 켜도** `READY` 가 뜨는지 (EEPROM 저장 확인)
- [ ] 각 시료를 다시 넣고 짧게 → 올바른 이름이 나오는지
- [ ] 엉뚱한 시료(예: 커피)를 넣었을 때 `UNKNOWN` 이 뜨는지

## 6. 성능 측정 (계획서 4.4.3절)

- [ ] **사이클 처리 시간** — PB5(D13) 펄스 폭을 오실로스코프로 측정.
      채널마다 펄스가 하나씩, 총 4개. **합산해서 기록한다.**
- [ ] **분류 정확도 + 혼동표** — 학습에 쓰지 않은 검증 시료로
- [ ] **채널별 재현성 CV** — 같은 시료 10회 반복
- [ ] **메모리 사용량** — Studio 빌드 화면 캡처
      (현재: Flash 6,634 B / 20.2%, SRAM 90 B / 4.4%)
- [ ] TIMEOUT 및 이상값 발생 빈도

## 문제가 생기면

| 증상 | 먼저 볼 곳 |
|---|---|
| 특정 채널만 `TIMEOUT: R` | 검출 LED 색상 (적색이어야 함) |
| 전 채널 `TIMEOUT` | 검출 LED 극성, 광량 부족 |
| `LOW SIGNAL` | 차광 과다 또는 `MIN_SIGNAL` 이 너무 높음 |
| 항상 `UNKNOWN` | `THRESHOLD_D2` 가 너무 작음 |
| 모든 시료가 같은 판정 | 시료 간 광학 차이 부족 → 4번으로 돌아갈 것 |
| 화면만 안 나옴 | I²C 주소·배선. UART 는 계속 나오는 것이 정상 |
