# 측정 프로토콜 체크시트

측정 당일 이 순서대로 진행한다. **인쇄해서 옆에 두고 체크하며 하는 것을 권한다.**
주입량 편차나 순서 착오는 데이터를 통째로 못 쓰게 만드는데, 측정 중에는
알아채기 어렵다.

- 근거: 계획서 4.1.3절(측정 순서), 6.4절(세척 절차), 6.6절(드리프트 대응)
- 관련 문서: `docs/superpowers/plans/2026-09-03-phase4-bringup.md` (하드웨어 연결 순서)

---

## 0. 측정 전 준비 — 측정 시작 최소 30분 전

- [ ] **차광 챔버 완성** — 빛이 새는 곳이 없는지 어두운 방에서 확인
- [ ] **일회용 큐벳(KA.CV-135, 광로 10mm)** 을 시료 수 + 예비만큼 꺼내 둠
- [ ] **큐벳 넣는 방향 확인** — 광로 10mm 방향이 광축과 일치해야 한다.
      90도 돌려 넣으면 광 경로가 4mm 로 바뀐다 (지그 방향 표시 확인)
- [ ] **경구용 주사기 5mL** 준비 — 표준 주입량을 매번 같게 맞춘다
- [ ] LED·큐벳 위치를 **고정** (테이프·클립). 측정 중 움직이면 데이터가 무의미해진다
- [ ] 증류수·식용색소·우유 준비, 상온으로 맞춤
- [ ] 보드 연결 후 `02_phase1` 업로드 완료
- [ ] 터미널 **38400 8N1** 연결, 로그 파일 저장 기능 켜둠
- [ ] `data/` 폴더 준비

> **온도.** 계획서 6.6절이 온도 드리프트를 지적한다. 에어컨·난방 바람이
> 직접 닿는 자리를 피하고, 측정 중 창문을 여닫지 않는다.

## 1. 시료 준비

| 시료 | 만드는 법 | 파일명 |
|---|---|---|
| 증류수 | 약국 증류수 그대로 | `data/distilled.csv` |
| 착색수 | 증류수 100mL + 식용색소 1~2방울 | `data/dye.csv` |
| 희석 우유 | 증류수 100mL + 무지방 우유 5mL | `data/milk.csv` |

- [ ] **희석 비율을 기록해둘 것.** 재현 실험과 PPT 서술에 필요하다
- [ ] 시료마다 **새 큐벳**을 쓴다 (일회용이므로 교차 오염이 원천적으로 없다)
- [ ] 주입량은 **전 시료 동일**하게. 값은 큐벳 도착 후 실측해서 정한다
      (`docs/차광챔버_제작.md` 4절). 액면이 광축보다 10mm 이상 위여야 한다

```
표준 주입량: ______ mL    광축 높이: ______ mm
```

## 2. 기준선 측정 — 세션 시작

- [ ] **빈 챔버(암실)** 10회 — 암전류 기준. Overflow Counter 동작 확인
- [ ] **증류수** 10회 → 이 값을 세션 시작 기준선으로 기록

```
세션 시작 증류수 평균: ________ us    시각: ______    실온: ______ ℃
```

## 3. 본 측정

각 시료마다 **10회 이상**. 한 시료가 끝나면 큐벳을 새것으로 바꾼다.

### 큐벳 교체 절차 — 매 시료 교체 시

계획서 6.4절의 세척 절차를 **일회용 큐벳 교체로 대체**한다. 헹굼 잔류물이
없으므로 교차 오염 위험이 사라지고, 세척 품질 편차도 데이터에 실리지 않는다.

- [ ] 쓴 큐벳은 버리고 **새 큐벳**을 꺼낸다
- [ ] 큐벳은 **위쪽 모서리만 잡는다** (광학면 지문이 광 경로를 막는다)
- [ ] 주사기로 **표준 주입량**을 주입. 벽을 타고 흘려 넣어 기포를 만들지 않는다
- [ ] **광로 10mm 방향**을 광축에 맞춰 넣는다
- [ ] 챔버 내부에 튄 액체가 있으면 닦아낸다
- [ ] 큐벳 외벽에 물기가 묻었으면 제거한 뒤 넣는다

### 측정 순서

- [ ] ① 빈 챔버 (암실) — 10회
- [ ] ② 증류수 — 10회 → `data/distilled.csv`
- [ ] ③ 착색수 — 10회 → `data/dye.csv`
- [ ] ④ 희석 우유 — 10회 → `data/milk.csv`
- [ ] ⑤ 광 경로 완전 차단 → **`TIMEOUT` 반환 확인** (예외 처리 검증)

> ⑤는 데이터 수집이 아니라 **예외 처리가 동작한다는 증거**다.
> PPT 슬라이드 14(예외 상황 대비)에 쓰이므로 화면·로그를 캡처해둔다.

## 4. 기준선 재측정 — 세션 종료

- [ ] **증류수** 10회 다시 측정

```
세션 종료 증류수 평균: ________ us    시각: ______    실온: ______ ℃
```

**시작과 종료의 차이가 5% 를 넘으면** 그 세션 데이터는 드리프트가 섞인
것으로 보고, 온도를 안정시킨 뒤 다시 측정한다.

## 5. 즉시 분석

측정이 끝나면 **그 자리에서** 돌린다. 문제가 있으면 장비를 치우기 전에
다시 재야 하기 때문이다.

```
python tools/analyze.py data/distilled.csv data/dye.csv data/milk.csv
```

- [ ] 조건 1 — 반복 측정 CV ≤ 10%
- [ ] 조건 2 — 시료 2종 이상 구분됨
- [ ] 조건 3 — Overflow / Timeout 정상 동작
- [ ] **출력 화면 캡처** (PPT 슬라이드 11에 들어간다)

## 실패했을 때

| 증상 | 먼저 볼 것 |
|---|---|
| CV > 10% | 외부광 유입, LED·큐벳 고정 상태, 온도 변동 |
| 시료 간 차이 없음 | 광량 부족 → 저항값 하향(220Ω), 발광–검출 거리 축소 |
| 시료 간 차이가 유난히 작음 | 미광 — 빛이 채널을 비껴감. 발광 LED 앞에 3mm 슬릿 (`차광챔버_제작.md` 4절) |
| 특정 채널만 TIMEOUT | 검출 LED 색상 (반드시 적색) |
| 전 채널 TIMEOUT | 검출 LED 극성 — 캐소드가 PD7인지 |
| 값이 계속 튐 | 큐벳 외벽 물기·지문, 시료 속 기포, 주입량 편차, 큐벳 방향 |

상세는 계획서 4.5절 실패 대응표와 `firmware/README.md` 5절.
