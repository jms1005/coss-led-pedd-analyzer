# 동작 동영상 촬영 시나리오

제출물 「라. 동작 동영상」용. **요강에 길이·형식 규정이 없다** —
운영설명 4항은 "라. 동작 동영상" 한 줄이 전부다. 따라서 심사위원이
끝까지 볼 만한 길이로 만드는 것이 유리하다.

**권장: 2분 30초 ~ 3분.** 평가 항목(운영설명 3항) 중 동영상으로 보여줄 수
있는 것은 **마. 완성도(동작 성능, 예외적 경우에 대한 대비)** 와
**바. 전달력** 이다. 이 둘을 노리고 구성한다.

---

## 촬영 전 반드시 정할 것

**차광 챔버와 조명이 충돌한다.** 측정은 어두워야 하고 촬영은 밝아야 한다.
이걸 미리 정하지 않으면 현장에서 헤맨다.

- 챔버는 **닫은 상태**로 촬영하고, 결과는 **OLED 화면**으로 보여준다
- 챔버 내부를 보여줄 장면은 **측정과 분리해서** 따로 찍는다
- 조명은 챔버 반대편에서, 화면에 반사가 생기지 않는 각도로

## 준비물

- [ ] 삼각대 또는 고정 거치대 (**손으로 들고 찍지 말 것** — OLED 글씨가 흔들려 안 읽힌다)
- [ ] OLED를 클로즈업할 수 있는 촬영 거리 확보
- [ ] 시료 3종 + 미학습 시료 1종(커피·주스 등) 미리 큐벳에 담아 정렬
- [ ] 보드에 `04_phase4` 업로드, **학습까지 완료된 상태**
- [ ] 조용한 환경 (내레이션을 넣을 경우)

## 장면 구성

### 1. 도입 — 15초

전체 장치를 한 화면에 담는다. 자막으로 작품명과 한 줄 요약.

> LED 다파장 재이용 광검출 기반 저비용 액체 광학 분석기
> "포토다이오드 없이, LED만으로 액체를 판별한다"

### 2. 구성 설명 — 30초

카메라를 천천히 이동하며 각 부분을 자막으로 짚는다.

| 보여줄 것 | 자막 |
|---|---|
| 발광 LED 3개 | R · G · B 발광부 (PB0~PB2) |
| 검출 LED | **검출 LED — 캐소드가 PD7. 이것 하나로 3파장을 모두 받는다** |
| 차광 챔버 | 외부광 차단 |
| OLED · 버튼 | 사용자 인터페이스 |

> 검출 소자가 **평범한 LED 한 개**라는 점이 이 작품의 핵심이다.
> 이 장면에서 확실히 전달되어야 한다.

### 3. 측정 시연 — 60초 (가장 중요)

**시료 3종을 순서대로.** 각 시료마다 같은 흐름을 반복한다.

```
큐벳 삽입 → 챔버 닫기 → 버튼 짧게 누름
  → OLED에 DARK/R/G/B 진행 표시가 하나씩 OK로 바뀜
  → 판정 결과 + 3채널 측정값 표시
```

- [ ] 증류수 → `DISTILLED WATER`
- [ ] 착색수 → `DYE WATER`
- [ ] 희석 우유 → `MILK`

**OLED 화면을 클로즈업으로 3초 이상 정지**해서 보여준다. 측정값(R/G/B us)이
시료마다 다르다는 것이 화면에서 읽혀야 한다.

### 4. 예외 처리 시연 — 30초

**이 장면을 빼지 말 것.** 요강 3-마가 "예외적 경우에 대한 대비"를 명시한다.

- [ ] **미학습 시료**(커피 등) 투입 → `UNKNOWN` 표시
- [ ] **광 경로 차단**(불투명 물체 삽입) → `TIMEOUT: R` 등 채널명과 함께 오류 표시
- [ ] 자막: "학습하지 않은 시료는 억지로 분류하지 않고 미상으로 판정한다"

> 대부분의 팀이 성공 장면만 찍는다. **실패를 정상적으로 처리하는 장면**이
> 완성도 점수에서 차별화된다.

### 5. 학습 모드 — 25초

- [ ] 버튼 **2초 길게** → `LEARN 1/3 DISTILLED WATER`
- [ ] 시료를 넣고 짧게 → 진행 → `2/3` → `3/3`
- [ ] `SAVED TO EEPROM`
- [ ] **전원을 뽑았다 다시 꽂아** `READY` 가 뜨는 것까지 보여준다

> 마지막 항목이 EEPROM에 실제로 저장됐다는 증거다. 말로 하는 것보다 강하다.

### 6. 마무리 — 20초

- [ ] UART 로그가 PC에 실시간으로 쌓이는 화면 (선택)
- [ ] 메모리 사용량: Flash 6,634 B (20.2%) / SRAM 90 B (4.4%)
- [ ] 자막: "Arduino 라이브러리 없이 레지스터 직접 제어"

## 재촬영을 줄이는 요령

| 실수 | 대비 |
|---|---|
| OLED 글씨가 안 읽힘 | 촬영 전 **한 컷 찍어서 확대 확인**. 초점·거리를 먼저 맞춘다 |
| 측정이 TIMEOUT 남 | 촬영 직전 리허설 1회. 광량·거리는 미리 확정해둘 것 |
| 손이 화면을 가림 | 버튼을 누르는 손과 OLED가 겹치지 않는 각도 |
| 화면 반사 | 조명을 정면이 아니라 측면·후면에서 |
| 시료 순서 혼동 | 큐벳에 라벨을 붙이고 순서대로 정렬해둔다 |

## 촬영 순서 제안

**장면 순서대로 찍지 말 것.** 장치 상태가 같은 것끼리 묶어 찍으면
셋업 변경이 줄어든다.

1. 먼저 **3(측정)·4(예외)** 를 연속 촬영 — 학습된 상태에서 한 번에
2. 그다음 **5(학습 모드)** — 상태를 바꿔야 하므로 나중에
3. 마지막에 **1(도입)·2(구성)·6(마무리)** — 정적인 장면이라 언제든 가능

## 편집

- 자막은 **화면 아래 고정 위치**에. 이리저리 옮기면 읽기 어렵다
- 측정 대기 시간(수 초)은 잘라내되, **너무 잘라 "빠르게 된다"는 인상을 주지 말 것**
  실제 사이클 시간이 얼마인지는 PPT 슬라이드에서 수치로 밝힌다
- 배경음악은 없어도 된다. 있다면 아주 작게
- 파일명 예: `LED_PEDD_동작동영상.mp4`

## 촬영 후 확인

- [ ] OLED 글씨가 **재생 화면에서** 읽히는가 (촬영 카메라 화면 말고)
- [ ] 3종 판정 + UNKNOWN + TIMEOUT 이 모두 담겼는가
- [ ] 전원 재투입 후 `READY` 장면이 있는가
- [ ] 길이가 3분을 크게 넘지 않는가
- [ ] 메일 첨부 가능한 용량인가 (초과 시 클라우드 링크 준비)
