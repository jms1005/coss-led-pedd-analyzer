## 1. 차광 챔버가 하는 일

이름은 "빛을 가린다"지만, 실제로는 **세 가지 역할**을 한다.
셋 다 만족해야 데이터가 나온다.

### 역할 ① 외부광 차단 — 측정 원리 자체가 걸려 있다

PEDD 방식은 역방향 바이어스된 검출 LED에 모아둔 전하가 **빛에 비례해
방전되는 시간**을 잰다. 즉 검출 LED는 **들어오는 모든 빛**에 반응한다.
시료를 통과한 빛인지 창문에서 들어온 빛인지 구별하지 못한다.

외부광이 들어오면 방전이 빨라져 방전 시간이 짧아지고, 그 값은 시료의
성질과 무관하다. **시료 정보가 외부광에 묻힌다.**

### 역할 ② 측정 편차(CV) 억제 — 합격 조건 1이 여기 걸려 있다

외부광이 문제인 진짜 이유는 밝아서가 아니라 **일정하지 않아서**다.

| 변동 요인 | 주기 |
|---|---|
| 형광등·LED등 플리커 | 100~120 Hz (사람 눈엔 안 보인다) |
| 구름, 시간대에 따른 창문 빛 | 수 분~수 시간 |
| 사람이 지나가며 만드는 그림자 | 불규칙 |

측정마다 외부광이 다르면 같은 시료를 재도 값이 튄다. 측정 프로토콜의
**조건 1 — 반복 측정 CV ≤ 10%** 가 여기서 무너진다.
챔버 없이 측정하면 십중팔구 이 조건에서 실패한다.

### 역할 ③ 암전류 보정을 유효하게 만든다

펌웨어는 매 사이클마다 **DARK 채널**(모든 LED를 끈 상태)을 먼저 재고,
그 값을 R·G·B에서 빼서 보정한다 (`classify.c`의 암 보정).

이 보정은 **DARK를 잴 때의 배경광과 R/G/B를 잴 때의 배경광이 같다**는
전제 위에 있다. 챔버가 없으면 그 사이 수십 ms 동안 형광등이 이미 몇 번
깜빡인 뒤다. 전제가 깨지면 보정이 오히려 오차를 더한다.

### 역할 ④ 광학 정렬 지그 — 사실 이게 더 중요할 수도 있다

챔버는 **발광 LED · 큐벳 · 검출 LED의 상대 위치를 고정**하는 틀이기도 하다.

빛의 세기는 거리의 제곱에 반비례한다. 발광–검출 거리가 30mm에서 33mm로
**10%만 변해도 도달 광량은 약 17% 줄어든다.** 시료 차이보다 큰 변화다.
측정할 때마다 손으로 LED를 놓는다면 데이터를 못 쓴다.

### 역할 ⑤ 내부 미광(stray light) 억제 — 내벽을 검게 하는 이유

빛이 흰 내벽에 반사되어 **큐벳을 통과하지 않고 우회해서** 검출 LED에
도달하면, 그 몫은 시료와 무관한 일정한 배경이 된다.
시료 간 차이가 그만큼 희석되어 분리도가 떨어진다.

> 정리하면, 챔버가 보장하는 것은 **"검출 LED에 도달하는 빛은 시료를
> 통과한 빛뿐이고, 그 경로는 매번 같다"** 는 조건이다.
> 이 문장이 실험의 전제 전부다.

## 2. 구조 — 투과 배치

계획서와 그림 1의 ③ 광학 경로에 해당한다. 한 직선 위에 놓는다.

```
        ┌─────────── 뚜껑 (여닫이) ───────────┐
        │                                     │
   ┌────┴─────┐      ┌──────┐      ┌──────────┴───┐
   │ 발광 LED │      │ 큐벳 │      │  검출 LED    │
   │ R  G  B  │─────>│ 시료 │─────>│  (캐소드 PD7)│
   │ PB0/1/2  │      └──────┘      └──────────────┘
   └──────────┘                       역방향 바이어스
        ↑                                    ↑
     한 번에 하나만 점등              모든 파장을 이 하나로 받는다
```

- 발광 LED 3개는 **한 번에 하나만** 켜지므로 서로 가까이 모아 둔다
- 세 개가 완벽히 같은 축에 있을 수는 없다. **괜찮다** — 채널마다 중심점
  (centroid)을 따로 학습하므로 채널 간 광량 차이는 흡수된다
- 단, **한 번 고정한 뒤에는 절대 움직이면 안 된다.** 움직이는 순간
  학습해 둔 중심점이 전부 무효가 된다

## 3. 재료 — 전부 다이소·문구점

| 재료 | 용도 | 비고 |
|---|---|---|
| 검정 우드락(폼보드) 5T | 챔버 본체 | 흰 우드락이면 내벽을 검게 처리해야 한다 |
| 검정 절연테이프 | 이음새 차광, 내벽 보강 | **넉넉히.** 가장 많이 쓴다 |
| 검정 무광 도화지 또는 검정 펠트 | 내벽 반사 억제 | 광택지는 안 된다 |
| 글루건 또는 목공풀 | 접합 | 글루건이 빠르고 틈을 메운다 |
| 커터칼, 30cm 자, 연필 | 재단 | 자는 금속자가 안전하다 |
| 5mm 드릴 또는 커터 | LED 구멍 | 없으면 커터로 십자 절개 후 밀어 넣는다 |

> **검정 골판지 상자나 검은 도시락통도 된다.** 재료보다 중요한 것은
> 아래 4절의 치수 원칙과 6절의 누광 검사다.

## 4. 치수 정하기 — 큐벳을 먼저 사서 재라

큐벳(다이소 소스통)의 실제 치수를 재고 나서 챔버 치수를 정한다.
반대 순서로 하면 다시 만들게 된다.

큐벳 폭을 `W`, 높이를 `H` 라 하면:

| 치수 | 값 | 이유 |
|---|---|---|
| 내부 폭 | `W + 40mm` | 좌우 각 20mm — LED와 벽 사이 여유 |
| 내부 깊이 | `W + 20mm` | 큐벳이 앞뒤로 흔들리지 않을 정도 |
| 내부 높이 | `H + 20mm` | 큐벳을 위에서 넣고 뺄 수 있게 |
| 발광–검출 LED 간 거리 | **30~40mm 로 시작** | 광량 부족하면 줄인다 |

**발광–검출 거리는 나중에 바꿀 수 있게 만드는 편이 좋다.** 첫 측정에서
전 채널 TIMEOUT이 뜨면 가장 먼저 손대는 값이 이것이기 때문이다.
LED를 벽에 접착하지 말고, **폼보드 조각에 꽂아 그 조각을 챔버 안에서
앞뒤로 옮길 수 있게** 하면 재제작 없이 조정된다.

## 5. 제작 순서

### ① 재단 — 6면

바닥 1, 옆벽 4, 뚜껑 1. 우드락 두께(5mm)를 고려해 겹침을 계산한다.
초보라면 **맞대기(butt joint)** 로 붙이고 이음새를 절연테이프로 덮는 편이
쉽다. 정밀도보다 차광이 우선이다.

### ② LED 구멍 — 아직 접착하지 않는다

마주 보는 두 벽에 구멍을 뚫는다.

- 발광 측: 5mm 구멍 3개, 서로 붙여서 (중심 간격 6~7mm)
- 검출 측: 5mm 구멍 1개, 발광부 3개의 **중앙 높이에 맞춰서**
- 구멍은 **LED가 뻑뻑하게 들어갈 정도**로. 헐거우면 흔들려서 정렬이 깨진다

### ③ 내벽 검게 처리

검정 무광 도화지를 안쪽 5면에 붙이거나, 검정 절연테이프를 겹치지 않게
발라 덮는다. **뚜껑 안쪽도 반드시** 처리한다. 위에서 반사되어 내려오는
빛이 의외로 크다.

### ④ 큐벳 자리 지그 — 재현성의 핵심

바닥에 우드락 조각으로 **ㄷ자 홈**을 만들어, 큐벳을 넣으면 항상 같은
자리에 안착하게 한다. 3면이 닿으면 위치가 한 곳으로 결정된다.

이 지그가 없으면 큐벳을 넣을 때마다 광 경로가 달라져서, 챔버를 만든
의미가 절반 사라진다.

### ⑤ 배선 구멍

**바닥 쪽 뒷벽에** 작게 하나만 뚫는다. LED 4개의 리드선이 여기로 나간다.
케이블을 통과시킨 뒤 **남는 틈을 검정 절연테이프로 완전히 막는다.**
빛은 생각보다 작은 틈으로 잘 들어온다.

### ⑥ 뚜껑 — 겹침 구조

단순히 위에 얹으면 테두리 틈으로 빛이 들어온다.
뚜껑 안쪽에 **테두리를 따라 우드락 띠를 둘러** 챔버 안쪽으로 물리게 한다.
빛이 꺾여 들어와야 하므로 직진광이 차단된다.

### ⑦ 가조립 후 정렬 확인 — 접착 전에 반드시

**여기를 건너뛰면 다시 만들게 된다.**

1. LED를 구멍에 꽂고 챔버를 테이프로 임시 고정
2. 발광 LED에 저항을 물려 켜 본다 (보드 없이 건전지로도 된다)
3. 큐벳을 넣고, **빛이 큐벳 중앙을 통과해 검출 LED 정면에 닿는지** 확인
4. 세 발광 LED 모두 확인
5. 맞으면 그때 접착

### ⑧ 최종 고정

정렬이 맞은 상태에서 LED를 글루건으로 고정한다.
**리드선 쪽에 힘이 걸리지 않게** — 나중에 케이블을 당기면 정렬이 틀어진다.

## 6. 누광 검사 — 두 단계로

### 1단계: 눈으로

- 불을 끈 방에서 챔버를 닫고, 밖에서 손전등을 여러 각도로 비춘다
- 안쪽에서 새어 들어오는 빛이 보이면 그 자리를 테이프로 막는다
- 이음새·배선 구멍·뚜껑 테두리 순으로 잘 샌다

### 2단계: 펌웨어로 — 이쪽이 확실하다

부품이 도착해 `02_phase1` 을 올린 뒤, **DARK 값으로 정량 검사**한다.

```
① 챔버를 닫고, 방 조명을 켠 상태에서 DARK 측정 10회
② 챔버는 그대로, 방 조명만 끄고 DARK 측정 10회
③ 두 평균값을 비교한다
```

| 결과 | 판정 |
|---|---|
| 두 값의 차이가 몇 % 이내 | 차광 성공 |
| 조명 켠 쪽이 **뚜렷하게 짧다** | 빛이 새고 있다 → 다시 막는다 |

방전 시간이 짧다 = 빛이 들어왔다는 뜻이다.
**이 검사 결과는 PPT에도 쓸 수 있다** — 요강 1-나 "겪은 문제와 해결"
항목의 재료가 된다. 수치를 기록해 둘 것.

## 7. 흔한 실수

| 실수 | 결과 | 대비 |
|---|---|---|
| 큐벳을 사기 전에 챔버를 만듦 | 큐벳이 안 들어가거나 헐렁함 | 큐벳 먼저 |
| 정렬 확인 전에 접착 | 빛이 검출 LED를 빗나감 → 전 채널 TIMEOUT | ⑦단계 필수 |
| 내벽이 흰색 | 미광으로 시료 간 차이가 희석됨 | 무광 검정 |
| 배선 구멍을 크게 뚫음 | 누광 | 최소로, 테이프로 마감 |
| 큐벳 지그 없음 | 넣을 때마다 값이 달라짐 (CV 초과) | ④단계 |
| LED를 벽에 완전 고정 | 광량 조정 불가 | 이동 가능한 조각에 꽂기 |
| 뚜껑을 그냥 얹음 | 테두리 누광 | 겹침 구조 |
| 만든 뒤 챔버를 옮김 | 정렬 변화. 학습한 중심점 무효 | 측정 자리에 두고 건드리지 않기 |
